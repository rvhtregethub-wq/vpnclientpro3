# VPNCLIENTPRO3 — GitHub Pages

## انتشار رایگان
1. در GitHub یک مخزن جدید با نام `vpnclientpro3` بسازید.
2. فایل‌های داخل این پوشه (`index.html`، `subscription.txt`، `servers.txt` و `.nojekyll`) را در ریشه مخزن بارگذاری کنید.
3. از Settings → Pages، گزینه Deploy from a branch را انتخاب کنید؛ Branch را `main` و Folder را `/ (root)` قرار دهید و Save بزنید.
4. پس از انتشار، صفحه در `https://USERNAME.github.io/vpnclientpro3/` و لینک اشتراک در `https://USERNAME.github.io/vpnclientpro3/subscription.txt` خواهد بود.

`subscription.txt` به صورت Base64 از لینک‌های VLESS/VMess/SS است و برای Subscription در کلاینت‌های سازگار استفاده می‌شود. `servers.txt` نسخه متنی خام است.

## به‌روزرسانی
برای تغییر سرورها، هر سه فایل خروجی را با نسخه جدید جایگزین کنید. GitHub Pages سرویس ایستا است و لینک اشتراک به‌صورت پویا سرورها را تازه نمی‌کند.

## امنیت
مخزن و فایل‌های اشتراک عمومی هستند. هر دارنده لینک می‌تواند کانفیگ‌ها را مشاهده کند. فقط کانفیگ‌هایی را منتشر کنید که مجاز به اشتراک‌گذاری آن‌ها هستید.
